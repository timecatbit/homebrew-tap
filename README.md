# timecatbit/tap

Homebrew casks for [Starmeter](https://github.com/timecatbit/starmeter), the menu bar monitor for AI coding tools' token usage, costs and limits.

```bash
brew install --cask timecatbit/tap/starmeter
```

Upgrade with `brew upgrade --cask starmeter`. The cask picks the disk image for your Mac's chip; each version's file and SHA-256 come from that release on GitHub.
