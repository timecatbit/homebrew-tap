# timecatbit/tap

Homebrew cask and formula for [Starmeter](https://github.com/timecatbit/starmeter), the menu bar monitor for AI coding tools' token usage, costs and limits.

The menu bar app (macOS):

```bash
brew install --cask timecatbit/tap/starmeter
```

The `starmeter` command on its own (macOS and Linux), for the same figures in a terminal:

```bash
brew install timecatbit/tap/starmeter-cli
```

Upgrade with `brew upgrade --cask starmeter` and `brew upgrade starmeter-cli`. The cask picks the disk image for your Mac's chip; each version's files and SHA-256 come from that release on GitHub.
